Important prototype notice

The ID generated here is a demo identifier only. It is not an official APAAR ID and is not connected to APAAR, DigiLocker, Aadhaar, AICTE, or government databases. Do not enter real Aadhaar numbers, certificates, or sensitive student data.

For a real deployment, official APAAR creation and verification must use authorized government integrations and consent-based processes. This prototype simulates the user journey only.

Register a new student

Complete this form once. The system will generate a unique demo APAAR ID after successful registration.

After registration, save your generated demo APAAR ID, open Student Login, and upload your supporting documents from your student dashboard.

Student Login

Use the email or demo APAAR ID received during registration, along with your password.

First time here?

A new student must register first. After registration, the system creates a demo ID and shows it once on the confirmation screen. Keep it for later login.

If you already have an official APAAR ID, this demo cannot look up or validate it. You can only log in using an ID generated inside this prototype.
